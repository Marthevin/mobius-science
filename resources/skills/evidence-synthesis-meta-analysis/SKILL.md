# Audited evidence synthesis and meta-analysis

Read [extraction-contract.md](references/extraction-contract.md) before extracting numbers and [methodology-notes.md](references/methodology-notes.md) before interpreting results. The one statistical authority is `scripts/run_meta_analysis.py`, using SciPy/NumPy/Matplotlib; this portable implementation replaces the proposed R/metafor engine for the tested route. R/metafor can independently cross-check results when available, but do not claim that comparison was run unless it was. For OpenCode/Notebook path boundaries, read [runtime-boundaries.md](references/runtime-boundaries.md).

1. Prespecify question, eligibility, effect direction, outcome, one effect measure, and analysis population in `config.json`. If literature driven, run `literature-deep-review` first and retain source IDs, full-text snapshots and screening reasons. If a user supplies the table, verify every number and citation against its original page before pooling. Never reconstruct numbers from memory.
2. Enter one independent study comparison per row in `extraction.csv`. Preserve the exact verbatim sentence/table row, page-indexed snapshot, source URL and source ID. The engine checks that effect and 95% CI numbers appear in the quoted source passage and recomputes SE on the analysis scale. Inaccurate transcription, mixed measures/designs/subgroups, duplicate cohorts, and unsafe snapshot paths fail closed. It cannot verify that authors computed the original effect correctly or that the quote is the right estimate for the question.
3. Run `python scripts/run_meta_analysis.py config.json extraction.csv output_dir` in a Python environment with SciPy, NumPy and Matplotlib. For OR/RR/HR, pool log effects and back-transform; for MD/SMD, pool on the reported scale. The default is random-effects REML with an ad-hoc Hartung–Knapp SE floor. Inspect the 95% confidence interval, prediction interval, τ², I², source-level extraction, all leave-one-out results, and conditional Cook's D/studentized residuals. Do not pool adjusted and unadjusted estimates or shared-control contrasts as independent effects.
4. Inspect each of the four exported PNG and SVG figures at final print size: forest, descriptive funnel, leave-one-out, and heterogeneity summary. The funnel and Egger route is **not interpretable for k < 10**; at k ≥ 10 it remains exploratory and may be skipped for inappropriate measures or inadequate size spread. An influential study merits source/method investigation, not automatic deletion. Do not infer clinical or substantive homogeneity from I² alone. When an explanatory infographic is needed, create that concept art with an image-generation tool and label it separately from data figures; do not disguise programmatic decoration as a scientific diagram.
5. Review `meta-report.md` against `meta-result.json` and source documents. Add risk of bias, certainty/applicability, screening flow, limitations and domain interpretation manually. Use `pdf-report-generation` or `docx-generation` to create the final document, run its quality gate, and inspect every rendered page. Record figure and document hashes in the QA note.

Stop and use a domain-specific model for single-arm prevalence, network meta-analysis, individual participant data, diagnostic accuracy, correlated/repeated effects, subgroup contrasts with shared arms, rare events or incompatible estimands. A statistically complete pooled estimate is not automatically a publishable systematic review.
