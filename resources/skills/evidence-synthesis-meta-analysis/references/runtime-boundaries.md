# Managed Skill execution

Install scientific Python dependencies through the managed Notebook environment, using its approved package/network path. If OpenCode marks a managed reference external, read it through `host.skills.read('evidence-synthesis-meta-analysis', 'references/extraction-contract.md')`; the same API can read `scripts/run_meta_analysis.py`. If the managed script is external to the Notebook workspace, create a complete session-local copy with matching SHA-256 and byte length, then execute that copy. Do not use `%run`, subprocess, shell, or importlib to bypass an external-path denial. Preserve Python and package versions, input hashes, original sources and final output hashes. If dependencies are unavailable, stop the pooled analysis; do not silently switch statistical methods.
