# PDF layout and visual QA

Choose the page count for the amount of evidence; do not compress a report into an arbitrary limit. For an A4 research report, start with comfortable margins, body text around 10–11 pt or larger, and enough line spacing for dense scientific prose. Captions and references should remain legible at normal page view. Keep table headings, units, axis labels, legends, and gene names large enough to read without zooming into an image. Flowing text belongs in the document layout, not rasterized inside a figure.

Use a font that covers every required script and Latin accent and embed it when the generator supports embedding. Check names with diacritics, Greek letters, mathematical symbols, and CJK text after export; a correct-looking DOI beside a corrupted author name is a document defect. If `pdffonts` is available, inspect its `emb` column and reject unembedded base-14 fonts such as Helvetica even when their text is not visibly obvious. Avoid a figure or table that is clipped, a caption separated from its figure, a section heading stranded at the page foot, and a reference list beginning on a nearly empty new page. If a page is mostly blank because of a forced break, rebalance the flow or use that space for a useful provenance appendix.

When using ReportLab Platypus, let sections and references flow rather than inserting a `PageBreak` for every section. Keep a heading with its first paragraph or table, and keep each figure with its caption. Set table column widths within the document's content frame and wrap long cell text; a table whose rightmost words disappear is not ready to export. Use `LongTable` or an equivalent for tables that span pages and repeat headers. Set `rl_config.canvas_basefontname`, every paragraph's `fontName` and `bulletFontName`, and the table-level `FONTNAME` to registered embedded fonts. ReportLab defaults in any one of those locations can emit Helvetica even when most visible text uses an embedded font. Verify markup is escaped exactly once: visible `&gt;` or `&amp;` in a scientific field definition is a text defect. Check legends and data labels at the figure's final printed size; no label should overlap plotted marks.

Do not place dozens of category labels on a page-width axis and rely on high DPI to make them readable. Show a justified top subset, aggregate the remainder, facet the comparison, or move the full ranked table to a machine-readable companion. For every dense figure, export at its final physical dimensions, render the PDF page, and confirm the smallest tick, legend, and annotation is readable at normal page view. A high-resolution image with illegible labels still fails review. Do not shrink a figure, table, or body text merely to satisfy a page limit; first remove repetition, improve the layout, or renegotiate an unjustified limit.

`doc.build(story)` consumes a Platypus story. After any correction, reconstruct a new story from the authoritative source and build once; filtering or reusing the already-built list can silently produce an empty or nearly empty PDF.

After generating, inspect **all** pages in the client's PDF preview or with an available renderer. If Poppler is available, `pdfinfo report.pdf` checks page count and size, `pdftoppm -png -r 120 report.pdf page` produces page images, and `pdftotext -layout report.pdf -` helps catch lost characters and reading-order problems. These checks complement visual review; they do not replace it. Inspect each page image at full-page view and at the scale the reader will use. Look for overflow, missing glyphs, thin or tiny plot labels, inconsistent whitespace, awkward line breaks, and references that are present but not linked or identified. Reject a page with a stranded heading, clipped table, overlapping legend, or large unused area caused by manual page breaks; change the source and render again.

For table-heavy reports, run a separate semantic-format pass on rendered pages. Never rely on a non-breaking space to force a long categorical value into a narrow cell: abbreviate it to a defined code, widen the column, or restructure the table, and preserve a visible gutter between adjacent columns. Keep counts as integers (`400`, not `400.000`), measurements at their justified precision, and confidence intervals in one deliberate unit such as `estimate (low–high)`. Replace machine field names (`coverage_sensor`, `drop_wifi`) with reader-facing labels unless the field name itself is the subject. Inspect every wrapped header and row in pixels; extracted text can be correct while glyphs from neighboring cells overlap.

For multi-panel figures, inspect internal labels, panel letters, legends, and annotations after the figure is placed at final page size. Canvas-bound and page-bound checks do not detect every collision inside the figure. When possible, calculate text/artist bounding-box intersections as a diagnostic, then still inspect the rendered page. A figure with a clean outer bounding box can contain severe internal overlap.

Check PDF metadata (`Title`, `Author`, `Creator`, `Producer`, `Subject`, and `Keywords`) against the requested product and manuscript identity. Inspect the final page separately: a technically nonblank page can still look unfinished when one short row or reference is stranded at the top. Reflow supplements or move a coherent block when the remaining whitespace is not intentional.

Run `scripts/pdf_quality_gate.py report.pdf --output-dir qa --language en --min-words 2500 --strict` for a full English research report, adjusting the justified word floor or language for the requested scope. If the brief requests 9–10 dense pages, for example, add `--min-pages 9 --max-pages 10 --max-bottom-blank 0.25`. The script renders page PNGs, creates a contact sheet, checks font embedding and leaked markup, validates a requested page range, and reports suspiciously sparse or bottom-heavy pages. A warning identifies a page to inspect; it does not prove the page is defective. Keep `qa/quality-report.json` with the deliverable's reproducibility record.

Record manual review page by page, for example: `p. 3 — table fits frame; legend clear; caption complete; no orphan heading`. Do not write one blanket line such as “all pages look good.” Inspect the contact sheet first for rhythm, density, and whitespace, then inspect every page at readable scale in manageable batches for text, figure, table, and citation details. For an English-only report, also scan extracted text for untranslated CJK prose and template placeholders.

If the runtime cannot display or inspect page pixels, state that visual QA is incomplete and do not report the PDF as visually passed. Delivering a contact sheet for someone else to inspect is useful evidence, but it is not a completed visual review. Bind the review to the final hash; a later rebuild invalidates the prior page images and verdict.

Revise the source document and render again after any content or layout change. Rerun the automated gate and reinspect changed pages; if pagination, shared styles, fonts, figures, tables, headers, or footers changed, reinspect every page. Verify the hash of the final PDF rather than relying on an older QA directory or a reused file name. Report the actual QA performed and do not infer page quality from file size, a `%PDF-` header, or `/Type /Page` byte counts.
