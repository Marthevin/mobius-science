# Bundled CJK proof font

`NotoSerifSC-Regular.otf` is the official Simplified Chinese region subset of
Noto Serif CJK from the [Noto CJK repository](https://github.com/notofonts/noto-cjk/tree/main/Serif/SubsetOTF/SC).
It is used by `docx_quality_gate.py` for local LibreOffice proof rendering.
SHA-256: `e8f396decc1f0963a016a989c3d8852e863d1350996f573860a80767c83a1cd3`.

This font is distributed under the SIL Open Font License 1.1; see `OFL.txt`.
It remains a separate licensed asset from the Skill code. A DOCX does not
embed this font: a recipient using Word needs the font installed or must
verify a deliberate substitute in their own editor.
